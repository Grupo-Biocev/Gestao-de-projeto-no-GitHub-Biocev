# Gestão de projeto no GitHub — Grupo Biocev

Manual interno do Grupo Biocev sobre gestão de projeto com o GitHub Project:
milestones, issues, dependências, visualizações Table, Board e Roadmap, backlog
e o fluxo Backlog → Ready → In progress → In review → Done com critérios de aceite.

**Acesse:** <https://grupo-biocev.github.io/Gestao-de-projeto-no-GitHub-Biocev/>

O conteúdo é protegido por senha com [quarto-lock](https://github.com/lsbjordao/quarto-lock):
este repositório contém apenas a tela de senha e arquivos cifrados (`*.qlock`).
A senha é distribuída internamente à equipe.

Este repositório é só a saída publicada. A fonte do manual fica em um repositório
privado; não edite os arquivos de `docs/` aqui, eles são gerados a cada publicação.
